# 호버 팝업 정보 구조 간소화 설계

## 목표

작업 표시줄 위젯에 이미 보이는 주간 사용량을 호버 팝업에서 반복하지 않고, 계정의 초기화 시각과 사용량 예측을 빠르게 읽을 수 있게 한다.

## 정보 구조

호버 팝업은 두 구획만 표시한다.

1. 계정
   - 선택된 사용량 프로필 이름
   - 바로 아래에 `초기화 시각: <현지 시각>`
   - 주간 창을 우선하고, 없으면 단기 창의 초기화 시각을 사용한다.
2. 사용량 예측
   - 소비 속도 요약
   - 최근 사용량 상세 설명
   - `단기`와 `주간` 예측을 같은 구획 안의 두 행으로 표시한다.

주간 사용량 제목, 퍼센트, 진행 막대는 제거한다. 단기·주간 예측 행 사이에는 별도 구획 구분선을 넣지 않는다.

## 레이아웃

- 모든 설명과 예측 문장은 현재 DPI와 실제 글꼴로 측정해 자동 줄바꿈한다.
- 말줄임표로 문장을 자르지 않는다.
- 측정된 문장 높이에 맞춰 다음 행과 팝업 전체 높이를 아래로 이동한다.
- 단기·주간 라벨은 한 구획 안에서 동일한 정렬과 간격을 사용한다.
- RTL 언어는 기존 정렬·읽기 방향 규칙을 유지한다.

## 데이터와 오류 처리

기존 `WidgetViewModel`의 소비 속도와 창별 예측 결과를 재사용하며 새 도메인 상태를 만들지 않는다. 초기화 시각이나 예측이 없으면 기존 지역화된 대체 문구를 유지한다. 네트워크·설정·폴링 동작은 변경하지 않는다.

## 검증

- 표시 모델이 중복 주간 사용량 필드를 더 이상 제공하지 않는지 확인한다.
- 초기화 시각이 계정 구획에 남고 주간 우선 규칙을 유지하는지 확인한다.
- 단기·주간 예측이 하나의 구획에 순서대로 포함되는지 확인한다.
- 긴 한국어·영어 설명이 줄바꿈되고 다음 행 및 팝업 높이를 밀어내는지 확인한다.
- LTR·RTL 텍스트 형식과 기존 접근성용 네이티브 툴팁 폴백을 유지한다.
