# 소비 속도 표시 설계

## 상태

- 설계 승인일: 2026-08-04
- 대상 플랫폼: Windows 10/11 x64 네이티브 Win32 UI
- 사용자 합의: 호버 툴팁에만 텍스트를 추가하고, 위젯 좌측 상단 상태점으로 소비 속도를 표현한다.

## 목적

사용자가 통계 용어나 원본 표본을 해석하지 않아도 현재 Codex 사용량 소비 속도가
`여유`, `보통`, `빠름` 중 어디에 해당하는지 즉시 알 수 있게 한다. 판정은 다른 사용자와 비교하지
않고, 현재 속도가 다음 초기화까지 남은 한도를 소진할 위험을 기준으로 한다.

## 비목표

- 토큰 수를 직접 수집하거나 추정하지 않는다.
- 다른 사용자, 요금제 또는 과거 프로필과 소비량을 비교하지 않는다.
- OpenAI의 실제 한도 정책을 예측하거나 보장하지 않는다.
- 설정 스키마나 사용량 이력 파일 형식을 변경하지 않는다.
- 위젯 본문에 새 텍스트, 범례 또는 추가 컨트롤을 넣지 않는다.
- 소비 속도 임계값을 사용자 설정으로 노출하지 않는다.

## 접근 방식 비교

### 1. 초기화까지 허용되는 속도와 실제 속도 비교 — 선택

현재 남은 사용량을 초기화까지 남은 시간으로 나눈 `안전 속도`와 최근 관측에서 계산한 실제
시간당 소비율을 비교한다.

- 장점: 현재 잔량과 초기화까지 남은 시간을 함께 반영한다.
- 장점: 단기·주간처럼 길이가 다른 창에도 같은 의미를 유지한다.
- 장점: `현재 속도면 초기화 전에 버티는가`라는 사용자 질문에 직접 답한다.
- 단점: 초기화 시각이 없거나 오래된 데이터만 있으면 판정할 수 없다.

### 2. 초기화 시 예상 잔여 사용량만 사용

초기화 시 예상 잔량이 많으면 여유, 적으면 보통, 소진되면 빠름으로 분류한다. 설명은 쉽지만
현재 잔량과 소비 속도의 의미가 섞여, 거의 소진된 채 사용하지 않는 상태를 빠른 소비로 오해할 수 있다.

### 3. 절대 시간당 소비율 사용

시간당 퍼센트 포인트에 고정 임계값을 적용한다. 구현은 단순하지만 초기화까지 2시간 남은 창과
7일 남은 창에서 같은 속도가 전혀 다른 위험을 만들기 때문에 제품 목표와 맞지 않는다.

## 판정 모델

### 입력 지표

기존 예측 엔진이 사용하는 동일 프로필·창·초기화 구간의 정제된 최근 표본에서 다음 값을 계산한다.

- 표본 수
- 첫 표본부터 마지막 표본까지의 관측 시간
- 관측 구간의 총 사용량 증가폭(퍼센트 포인트)
- Theil-Sen 중앙 기울기로 계산한 시간당 소비율(퍼센트 포인트/시간)

동일 시각 중복 제거, 최근 32개 제한, 1퍼센트 포인트 이하 하락의 노이즈 평탄화, 더 큰 하락 이후
새 구간 시작 규칙은 기존 예측 계산과 공유한다. 속도 계산을 위해 이 규칙을 복제하지 않는다.

### 측정 준비 조건

소비 속도 등급은 같은 초기화 구간에서 표본 3개 이상, 관측 시간 30분 이상일 때만 산출한다.
조건을 충족하지 못하면 `측정 중`이다. 기존 소진 시각 예측이 요구하는 총 1퍼센트 포인트 상승과
시간당 0.05퍼센트 포인트 기준은 속도 등급에는 적용하지 않는다. 낮은 활동을 `여유`로 표현하는 것이
이번 기능의 핵심이기 때문이다.

### 속도 비율

초기화 시각이 현재보다 뒤이고 현재 사용량이 100% 미만일 때 다음 값을 계산한다.

```text
안전 속도 = 현재 남은 사용량 / 초기화까지 남은 시간
속도 비율 = 실제 시간당 소비율 / 안전 속도
```

실제 시간당 소비율은 음수가 되지 않게 0으로 제한한다. 안전 속도가 0이거나 현재 사용량이 이미
100% 이상이면 소진 상태로 처리한다.

### 등급

| 상태 | 조건 | 점 색상 | 사용자 의미 |
| --- | --- | --- | --- |
| 여유 | 속도 비율 `< 0.5` | 초록 | 현재 속도가 초기화 전 소진 속도의 절반보다 느림 |
| 보통 | `0.5 <=` 속도 비율 `< 1.0` | 주황 | 현재 속도면 버티지만 여유가 크지 않음 |
| 빠름 | 속도 비율 `>= 1.0` | 빨강 | 현재 속도면 초기화 전에 소진될 수 있음 |
| 측정 중 | 표본 또는 관측 시간 부족 | 회색 | 아직 안정적인 속도를 계산할 수 없음 |
| 판단 불가 | 초기화 시각 없음, 오래됨 또는 입력 오류 | 회색 | 현재 데이터로 속도를 판단할 수 없음 |
| 꺼짐 | 사용량 소진 예측 기능 비활성화 | 회색 | 기록과 소비 속도 표시가 꺼져 있음 |
| 소진됨 | 현재 사용량 100% 이상 | 빨강 | 현재 창의 한도가 이미 소진됨 |

경계값은 고정된 제품 규칙이다. 설정이나 언어에 따라 달라지지 않는다.

## 창 선택

좌측 상단 점과 소비 속도 요약은 현재 작업 표시줄 위젯이 표시하는 한도 창을 따른다. 보조 창이
있으면 보조 창을 사용하고, 없으면 기본 창을 사용한다. 즉 점의 등급, 위젯 퍼센트, 진행 막대가
같은 창을 설명한다.

기존 호버 툴팁의 기본·보조 창별 소진 예측은 유지한다. 소비 속도 요약은 점이 나타내는 선택 창에
대해서만 한 번 표시해 두 창의 등급을 한 점에 억지로 합치지 않는다.

## 위젯 표시 계약

### 상태점

- 정상 조회이고 속도 등급을 계산할 수 있으면 점은 `여유/보통/빠름` 색상을 사용한다.
- 측정 중, 판단 불가 또는 예측 기능이 꺼져 있으면 회색 점을 사용한다.
- 첫 조회 전 로딩은 기존 회색 점을 유지한다.
- 최근 조회 오류는 소비 속도보다 우선하며 기존 빨간 `!` 표시를 유지한다.
- 최소 폭 레이아웃이 점을 숨기는 기존 적응형 규칙은 유지한다. 이때 속도는 호버 툴팁으로 확인한다.

점은 소비 속도만 나타낸다. 진행 막대와 퍼센트는 계속 현재 사용량을 나타내며, 진행 막대 색은 기존
사용량 위험도 색상을 유지한다. 렌더러는 점 색과 진행 막대 색을 별도로 선택해야 한다. 예를 들어
현재 사용량이 95%지만 소비가 멈춘 상태는 빨간 진행 막대와 초록 점으로 표시될 수 있다.

### 호버 문구

한국어 준비 완료 상태는 다음 두 줄을 사용한다.

```text
소비 속도: 여유
최근 2시간 동안 3% 사용 · 시간당 약 1.5%
```

등급별 설명은 기존 소진 예측과 중복되지 않게 짧게 유지한다.

- 여유/보통이고 초기화 시 예상 잔량을 계산할 수 있으면 기존 `초기화 시 약 N% 남을 것으로 예상`
  문구를 그대로 이어 붙인다.
- 빠름이면 기존 `초기화 전에 소진할 가능성이 높음` 문구를 사용한다.
- 7일 이상 장기 예측 문구와 기본·보조 창별 예측 순서는 유지한다.

측정 중에는 통계 용어 대신 진행 조건을 보여 준다.

```text
소비 속도 측정 중 · 데이터 2/3 · 관측 20/30분
```

판단 불가 상태는 원인을 세분해 내부 오류를 노출하지 않고 다음처럼 축약한다.

```text
소비 속도를 판단할 수 없음 · 최신 사용량과 초기화 시각이 필요함
```

예측 기능을 끈 상태에서는 회색 점의 이유를 호버에서 명시한다.

```text
소비 속도 표시 꺼짐
```

소수 퍼센트는 한 자리까지 표시하되 정수이면 소수점을 생략한다. 시간당 속도가 0에 가까우면
`시간당 0%`로 표시한다. 관측 시간은 분, 시간, 일 중 가장 이해하기 쉬운 기존 지역화 단위를
재사용한다. 화면에는 `Theil-Sen`, `기울기`, `퍼센트 포인트`, `신뢰도` 같은 통계 용어를 노출하지
않는다.

새 문구는 한국어와 영어를 포함한 기존 12개 언어에 모두 추가한다. 색상만으로 의미를 전달하지
않도록 호버 텍스트가 항상 동일한 상태를 설명해야 한다.

## 데이터 및 컴포넌트 경계

### `src/forecast.rs`

- 기존 정제 표본으로 예측 결과와 소비 속도 평가를 한 번에 만드는 분석 경계를 추가한다.
- 기존 공개 `ForecastEngine::calculate`는 호환성을 위해 예측 결과만 반환하는 wrapper로 유지한다.
- 소비 속도 평가에는 등급, 표본 수, 관측 시간, 총 증가량, 실제 시간당 속도와 예상 초기화 잔량만
  포함한다.
- 기존 소진 예측의 최소 상승량, 최소 속도와 품질 등급 규칙은 변경하지 않는다.

### `src/usage_forecast.rs`

- 성공 표본을 처리할 때 예측 결과와 소비 속도 평가를 한 번만 계산해 같은 캐시에 저장한다.
- 기존 `forecast_at` 계약은 유지하고, 선택 창의 소비 속도 평가를 읽는 별도 조회 경계를 추가한다.
- 비활성화, 이력 삭제, 프로필 제거와 세대 변경 시 예측과 속도 캐시를 함께 비운다.
- 오래된 캐시는 예측과 속도 모두 판단 불가 상태로 변환한다.

### `src/app.rs`, `src/windows/mod.rs`

- 애플리케이션 계층이 엔진 결과를 지역화된 호버 문구와 렌더러용 타입 상태로 변환한다.
- `WidgetViewModel`에는 문자열 비교 없이 점을 그릴 수 있는 타입 지정 소비 속도 상태를 추가한다.
- 점이 나타내는 선택 창과 호버 소비 속도 요약은 동일한 선택 helper를 사용한다.
- 기존 기본·보조 창별 소진 예측 문구와 프로필 안내를 보존한다.

### `src/windows/taskbar_widget.rs`, `src/windows/native/platform.rs`

- 작업 표시줄 레이아웃과 점 위치는 변경하지 않는다.
- 기존 사용량 위험도 타입은 진행 막대 색에 계속 사용한다.
- 소비 속도 상태는 점 색에만 사용하고, 오류 `!`와 로딩 우선순위를 보존한다.
- Win32 렌더러에서 색상 선택 이외의 I/O나 계산을 수행하지 않는다.

### `src/localization.rs`

- 소비 속도 등급, 측정 중, 판단 불가, 꺼짐과 최근 관측 요약 문구를 12개 언어에 추가한다.
- 제어 흐름은 지역화 문자열이 아니라 타입 상태를 사용한다.

## 데이터 흐름

```text
성공한 app-server 사용량 조회
  -> 기존 프로필·창별 이력 기록
  -> 정제 표본 분석(예측 + 소비 속도)
  -> 메모리 캐시
  -> AppRuntime 지역화/표시 모델
  -> 좌측 점 색상 + 호버 툴팁
```

소비 속도 지표는 기존 `usage-history.json` 표본에서 매번 파생하며 새 필드를 저장하지 않는다.

## 오류 처리와 보안 경계

- 토큰 수, 계정 ID, 이메일, 인증 정보, 원본 RPC payload를 추가로 수집하거나 저장하지 않는다.
- 사용자 화면과 진단 로그에 프로필 경로 또는 계정 식별 정보를 노출하지 않는다.
- 손상 표본, 혼합 스트림, 미래 시각, 초기화 시각 부재와 오래된 캐시는 빠른 소비로 추측하지 않고
  판단 불가로 안전하게 실패한다.
- 예측 기능을 끄면 기록과 계산을 중단하고 점은 회색으로 표시하며, 호버에는 소비 속도 표시가
  꺼졌음을 명시한다.
- 조회 실패 시 마지막 정상 사용량 보존 정책은 유지하되 빨간 `!`가 속도 점보다 우선한다.

## 테스트 전략

### 계산

- 3개 표본과 30분 경계 직전은 측정 중, 정확한 경계는 등급 계산 가능 상태다.
- 기존 예측이 `InsufficientActivity`인 평탄하거나 낮은 활동도 소비 속도 `여유`로 계산된다.
- 속도 비율 0.5와 1.0의 경계를 각각 `보통`, `빠름`으로 분류한다.
- 초기화 시각 없음, 지난 초기화 시각, 오래된 데이터와 유효하지 않은 표본은 판단 불가다.
- 현재 사용량 100% 이상은 소진됨이다.
- 초기화 구간 변경과 1퍼센트 포인트 초과 하락은 새 측정 구간을 시작한다.
- 예측 결과와 소비 속도 분석이 동일한 정제 표본과 Theil-Sen 속도를 공유한다.

### 서비스와 상태

- 프로필·기본/보조 창별 예측과 속도 캐시가 서로 섞이지 않는다.
- 기능 끄기, 기록 삭제, 프로필 제거와 재등록은 속도 캐시도 제거한다.
- 저장 실패는 속도 표시나 마지막 정상 사용량을 지우지 않는다.
- 새 성공 표본 없이 오래된 캐시를 현재 속도로 표시하지 않는다.

### UI와 지역화

- 보조 창 우선, 기본 창 fallback이 점과 호버 요약에 동일하게 적용된다.
- 정상 상태에서 점은 속도 색, 진행 막대는 현재 사용량 위험 색을 각각 사용한다.
- 로딩은 회색 점, 오류는 빨간 `!`로 속도 상태보다 우선한다.
- 모든 12개 언어에서 등급·측정·판단 불가·꺼짐 문구가 비어 있지 않고 숫자 치환이 완료된다.
- 최소 폭에서 점이 숨겨져도 퍼센트와 진행 막대가 기존 경계를 벗어나지 않는다.

## 문서 변경

- `README.md`와 한국어 번역 README에 소비 속도 점과 판정 기준을 설명한다.
- `docs/ACCOUNT_STORAGE.md`에는 새 개인정보를 저장하지 않고 기존 사용량 비율 표본에서 파생한다는
  점을 명시한다.
- `docs/RELEASE_CHECKLIST.md`에 등급 경계, 저활동 여유 상태, 점/진행 막대 색 분리와 오류 우선순위의
  수동 검증 항목을 추가한다.

## 승인 기준

- 정상 상태의 좌측 상단 점이 표시 중인 한도 창의 소비 속도를 초록/주황/빨강으로 나타낸다.
- 로딩 회색 점과 오류 빨간 `!`의 기존 복구 의미를 보존한다.
- 진행 막대는 현재 사용량 위험도, 점은 소비 속도라는 서로 다른 의미를 유지한다.
- 호버 툴팁에 등급과 최근 관측 시간·증가량·시간당 속도가 쉬운 문장으로 표시된다.
- 낮은 활동도 충분한 표본과 관측 시간이 있으면 `여유`로 표현된다.
- 기존 소진 시각 예측의 엄격한 표시 기준과 설정·이력 스키마·보안 경계가 유지된다.
- 자동 품질 게이트가 통과하고 필요한 Windows 수동 검증 항목이 명시된다.
