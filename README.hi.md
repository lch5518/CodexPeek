# Codex Usage Monitor

**Languages:** [English (default)](README.md) · [한국어](README.ko.md) · [Español](README.es.md) · [Português (Brasil)](README.pt-BR.md) · [Bahasa Indonesia](README.id.md) · [日本語](README.ja.md) · [हिन्दी](README.hi.md) · [Deutsch](README.de.md) · [Français](README.fr.md) · [Tiếng Việt](README.vi.md) · [Türkçe](README.tr.md) · [العربية](README.ar.md)

Codex Usage Monitor एक छोटा मूल Windows विजेट है, जिससे आप अपना Codex उपयोग एक नज़र में देख सकते हैं।
यह प्राथमिक और द्वितीयक दर-सीमा अवधियां टास्कबार, तैरते विजेट और सिस्टम ट्रे में दिखाता है।

![Codex Usage Monitor टास्कबार विजेट](docs/images/taskbar-widget-en.png)

## मुख्य बातें

- रीसेट समय सहित प्राथमिक और द्वितीयक Codex उपयोग अवधियां दिखाता है।
- प्रमाणीकरण फ़ाइलों को पढ़ने के बजाय स्थापित Codex CLI के `app-server` इंटरफ़ेस का उपयोग करता है।
- विजेट को हर टास्कबार पर या केवल मुख्य मॉनिटर पर दिखाने का विकल्प देता है।
- टास्कबार से जुड़ना उपलब्ध न होने पर सुरक्षित रूप से तैरते विजेट और ट्रे आइकन पर लौटता है।
- हाथ से ताज़ा करना, स्वतः ताज़ा अंतराल, Windows के साथ शुरुआत, निदान और स्थानीयकृत UI का समर्थन करता है।

## यह कैसे काम करता है

मॉनिटर `codex app-server --stdio` को स्थानीय चाइल्ड प्रोसेस के रूप में शुरू करता है और मानक इनपुट व आउटपुट पर JSONL संदेशों का आदान-प्रदान करता है।
स्थापित Codex CLI अपना प्रमाणीकरण स्वयं संभालता है और अपनी मौजूदा कॉन्फ़िगरेशन तथा नेटवर्क नीति के तहत OpenAI से संपर्क कर सकता है।

मॉनिटर केवल साइन-इन स्थिति और प्रदर्शन के लिए आवश्यक उपयोग अवधियां मांगता है।
यह कोई Codex कार्य शुरू नहीं करता और `codex exec` नहीं चलाता।

## आवश्यकताएं

- Windows 10 या Windows 11, x64।
- `account/read` और `account/rateLimits/read` का समर्थन करने वाला साइन-इन किया हुआ [Codex CLI](https://github.com/openai/codex)।

## डाउनलोड करें और चलाएं

पहले पुष्टि करें कि Codex CLI स्थापित है और साइन-इन किया हुआ है:

```powershell
codex --version
codex login status
```

### इंस्टॉलर (अनुशंसित)

1. [नवीनतम GitHub Release](https://github.com/lch5518/CodexPeek/releases/latest) से
   `CodexPeek-Setup-v<version>-x64.exe` डाउनलोड करें।
2. सेटअप चलाएं और निर्देशों का पालन करें। प्रशासक अनुमति आवश्यक नहीं है।
3. Start Menu से **Codex Usage Monitor** शुरू करें।

### पोर्टेबल संस्करण

1. नवीनतम रिलीज से
   `codex-peek-v<version>-windows-x86_64-portable.zip` डाउनलोड करें।
2. ZIP को किसी लिखने योग्य फ़ोल्डर में पूरी तरह निकालें।
3. निकाले गए फ़ोल्डर से `codex-peek.exe` चलाएं।

### स्रोत से बनाएं

इस विकल्प के लिए Rust 1.85 या बाद का संस्करण, Visual Studio 2022 C++ Build Tools और
Windows SDK चाहिए। यह क्लोन किए गए भंडार से ऐप चलाता है और Start Menu शॉर्टकट या
अनइंस्टॉलर नहीं बनाता।

```powershell
git clone https://github.com/lch5518/CodexPeek.git
Set-Location .\CodexPeek
cargo build --release
.\target\release\codex-peek.exe
```

UI खोले बिना बिल्ड और Codex CLI कनेक्शन जांचने के लिए:

```powershell
.\target\release\codex-peek.exe --diagnose
```

### Codex से स्थापना करवाएं

नीचे दिया गया प्रॉम्प्ट Codex में कॉपी करें। यह सत्यापित इंस्टॉलर को प्राथमिकता देता है और संगत रिलीज फ़ाइलें उपलब्ध न होने पर ही
स्रोत बिल्ड पर लौटता है।

```text
इस Windows x64 कंप्यूटर पर CodexPeek स्थापित करें और मेरे लिए सत्यापन पूरा करें।

1. पुष्टि करें कि यह Windows x64 है, फिर `codex --version` और `codex login status` चलाएं।
2. केवल आधिकारिक repository और उसके Releases का उपयोग करें:
   https://github.com/lch5518/CodexPeek
3. नवीनतम `CodexPeek-Setup-v<version>-x64.exe` को प्राथमिकता दें। इसे
   `SHA256SUMS.txt` के साथ डाउनलोड करें, उस फ़ाइल में Installer की ठीक वही प्रविष्टि खोजें,
   Installer का SHA-256 निकालें, और हैश मेल खाने पर ही आगे बढ़ें। सुरक्षा नियंत्रण बंद न करें
   और ऐसी फ़ाइल न चलाएं जिसका checksum अनुपस्थित या अलग हो।
4. प्रशासक अनुमति मांगे बिना इसे मौजूदा उपयोगकर्ता के लिए स्थापित करें। मौजूदा
   CodexPeek settings सुरक्षित रखें और चल रही ऐप या असंबंधित प्रक्रिया को बंद न करें;
   अगर मुझे ऐप स्वयं बंद करनी हो, तो पहले मुझे बताएं।
5. संगत रिलीज फ़ाइलें उपलब्ध न होने पर ही आधिकारिक repository को किसी नए
   उपयोगकर्ता-लिखने योग्य directory में clone करें और `cargo build --release` चलाएं। अगर Git, Rust
   1.85+, Visual Studio 2022 C++ Build Tools या Windows SDK स्थापित करना पड़े, तो पहले
   ठीक-ठीक समझाएं कि क्या बदलेगा और मेरी स्वीकृति मांगें।
6. `%USERPROFILE%\.codex\auth.json` की सामग्री कभी न पढ़ें और न मुद्रित करें। प्रमाणीकरण
   केवल स्थापित Codex CLI के माध्यम से ही संभाला जाना चाहिए।
7. स्थापना या बिल्ड के बाद बने हुए `codex-peek.exe --diagnose` को चलाएं। अगर यह
   सफल हो, तो CodexPeek शुरू करें।
8. चुनी गई स्थापना विधि, स्थापित संस्करण, निष्पादन योग्य फ़ाइल का स्थान, checksum परिणाम
   और निदान परिणाम बताएं। अगर कुछ विफल हो, तो संवेदनशील जानकारी उजागर किए बिना
   सुरक्षित रूप से रुकें और सटीक अवरोध समझाएं।
```

इंस्टॉलर और पोर्टेबल संस्करण `%APPDATA%\CodexUsageMonitor\settings.json` का उपयोग करते हैं, इसलिए
इनके बीच बदलने पर सेटिंग्स साझा रहती हैं। इंस्टॉलर Start Menu शॉर्टकट जोड़ता है
लेकिन डिफ़ॉल्ट रूप से Windows startup सक्षम नहीं करता।

प्रारंभिक रिलीज code-signed नहीं हैं और Microsoft Defender SmartScreen चेतावनी दिखा सकता है।
केवल आधिकारिक रिलीज से डाउनलोड करें और फ़ाइल को `SHA256SUMS.txt` से सत्यापित करें।

हैश सत्यापन, अपडेट, अनइंस्टॉल व्यवहार, निदान और समस्या-निवारण के लिए [विस्तृत स्थापना मार्गदर्शिका (Korean)](docs/INSTALL.md) देखें।

## मॉनिटर का उपयोग

ट्रे मेनू से उपयोग ताज़ा करें, 1/5/10/15/30 मिनट का ताज़ा अंतराल चुनें, और विजेट दिखाएं या छिपाएं।
इसमें Windows startup, प्रारंभिक दृश्य, प्रमाणीकरण ताज़ा करना, स्वतः प्रमाणीकरण ताज़ा करना, भाषा और निदान सेटिंग्स भी हैं।
कई मॉनिटर पर स्थान नियंत्रित करने के लिए **विजेट: सभी मॉनिटर** या **विजेट: केवल मुख्य मॉनिटर** चुनें; चयन पुनः शुरू करने के बाद भी याद रखा जाता है।

डिफ़ॉल्ट रूप से UI भाषा Windows locale का पालन करती है, यदि वह समर्थित भाषा से मेल खाती है। आप ट्रे मेनू से भाषा हाथ से भी चुन सकते हैं। समर्थित भाषाएं हैं: Korean, English, Spanish, Brazilian Portuguese, Indonesian, Japanese, Hindi, German, French, Vietnamese, Turkish और Arabic।

टास्कबार विजेट अपने पाठ के लिए Windows की light/dark सिस्टम थीम का उपयोग करता है और मूल टास्कबार सामग्री को पृष्ठभूमि में दिखने देता है।

एक समय में केवल एक उपयोग अनुरोध चलता है। विफल अनुरोध बढ़ती देरी के साथ फिर प्रयास करते हैं, जबकि अंतिम सफल मान दिखाई देते रहते हैं।

Explorer पुनः शुरू होने या टास्कबार लेआउट बदलने के बाद टास्कबार विजेट जुड़ न पाए, तो ट्रे आइकन उपलब्ध रहता है और मॉनिटर सुरक्षित रूप से फिर प्रयास करता है।

## निजता और सुरक्षा

मॉनिटर `%USERPROFILE%\.codex\auth.json` की सामग्री कभी नहीं पढ़ता और न ही पार्स करता है।
निदान केवल यह जांचता है कि वह पथ मौजूद है या नहीं।

कच्चे RPC उत्तरों को केवल लॉगिन प्रकार और दिखाए जाने वाले दर-सीमा फ़ील्ड निकालने जितनी देर संसाधित किया जाता है।
टोकन, खाता ID, ईमेल पते, प्रमाणीकरण-फ़ाइल सामग्री और प्रॉक्सी मान संग्रहीत नहीं किए जाते और लॉग में नहीं लिखे जाते।

सेटिंग्स `%APPDATA%\CodexUsageMonitor\settings.json` में संग्रहीत होती हैं।
सीमित निदान लॉग `%TEMP%\codex-peek.log` में संग्रहीत होता है।

पूरे डेटा-प्रबंधन और असुरक्षा-रिपोर्टिंग मार्गदर्शन के लिए [SECURITY.md](SECURITY.md) देखें।

## समस्या-निवारण

| समस्या | क्या करें |
| --- | --- |
| Codex CLI नहीं मिला | `codex --version` और `where.exe codex` चलाएं, फिर सुनिश्चित करें कि Codex CLI `PATH` पर है। |
| CLI समर्थित नहीं है | Codex CLI अपडेट करें। आवश्यक RPC समर्थन दिखाए गए संस्करण नंबर से अधिक महत्वपूर्ण है। |
| लॉग आउट हैं या प्रमाणीकरण समाप्त हो गया है | Codex CLI में सामान्य लॉगिन प्रवाह पूरा करें, फिर ट्रे मेनू में **प्रमाणीकरण ताज़ा करें** चुनें। |
| टास्कबार विजेट गलत मॉनिटर पर है | ट्रे मेनू से **विजेट: सभी मॉनिटर** या **विजेट: केवल मुख्य मॉनिटर** चुनें। |
| टास्कबार विजेट दिखाई नहीं दे रहा | तैरते विजेट या ट्रे आइकन का उपयोग करें, जरूरत हो तो Explorer फिर शुरू करें, और पसंदीदा विजेट मॉनिटर मोड चुनें। |
| अधिक विवरण चाहिए | `--diagnose` चलाएं या ट्रे मेनू से **निदान** खोलें। |

## विकास

Windows SDK चाहिए। भंडार की जड़ से बनाएं और सत्यापित करें:
